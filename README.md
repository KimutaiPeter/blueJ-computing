## b) Method Overloadingin and Overriding
# Method Overloading
Overloading allows different methods to share the same name but with different signatures, these differences can be:
- different number of input arguments
- Different types of input arguments
- Different order of the arguments
Here, the class MathOperations having 2 methods with the name multyply, one has 2 arguments while the other has 3 arguments

# Method Overriding
Overriding allows methods in the parent class to be redifined in the child class.
Here the child classes Dog and Cat have overriden the method makeSound defined in the parent class Animal
